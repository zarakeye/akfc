**À quoi ça sert.** Une discipline est un art enseigné par le club. Elle a sa page publique, une carte facultative sur la page d'accueil, et c'est à elle que se rattachent les cours.

**Avant de commencer.** Être administrateur. Panneau de contrôle → **Catalogue des activités** → **Disciplines**. Pour ranger la discipline dans le menu, créez d'abord sa **famille** ; pour lui donner une origine, l'**origine culturelle**.

## Les étapes

1. Cliquez sur **Créer une discipline**.
2. **Identité** : le nom, le slug (l'adresse de sa page, rempli d'après le nom, régénérable), le type (**Art martial** ou **Calligraphie**), la catégorie et l'instructeur principal. Tous sont obligatoires ; la catégorie ne se change plus ensuite.
3. **Origine et classification**, facultatifs : l'origine culturelle, la famille (qui la range dans le menu **Nos disciplines**), l'école, la classification.
4. **Description** : le contenu de sa page, composé avec le constructeur.
5. **Présentation synthétique** : une image et quelques lignes, en carte sur la page d'accueil avec un lien vers la page complète. Vide, la discipline ne figure pas sur l'accueil.
6. **Enregistrer en brouillon** la garde invisible du public ; **Publier** la met en ligne aussitôt.

<Callout type="info">
Les cours d'une discipline n'ont pas de publication propre : ils sont visibles dès que leur discipline est publiée.
</Callout>
