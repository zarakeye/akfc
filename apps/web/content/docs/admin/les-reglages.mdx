**À quoi ça sert.** L'identité du site se règle ici, sans toucher au code. Les réglages techniques (stockage, adresse du site, e-mails du serveur) restent l'affaire du développeur.

**Avant de commencer.** Être administrateur. Panneau de contrôle → **Configuration & outils** → **Réglages du site**.

## Les parties

- **Les titres** : le titre court (en-tête, onglet du navigateur, e-mails), le titre long, l'accroche (pied de page, description pour les moteurs de recherche), l'e-mail cité dans l'e-mail de bienvenue. Bouton **Enregistrer**.
- **Le logo** : un fichier SVG de 512 Ko au plus, enregistré dès qu'on le choisit.
- **Les coordonnées publiques** : e-mail, téléphones, adresse, affichés à tous sur **Nous contacter**. Bouton **Enregistrer les coordonnées**.
- **Les informations légales** : les pages **Mentions légales** et **Politique de confidentialité** sont générées à partir de ces seuls champs. Bouton **Enregistrer les informations légales**.
- **Les partenaires** : la MJC, la fédération… Leurs logos s'affichent dans le pied de page et sur **S'inscrire**.

<Callout type="info">
Chaque partie a son propre bouton : enregistrer les titres n'enregistre pas les coordonnées.
</Callout>
