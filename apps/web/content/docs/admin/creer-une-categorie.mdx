**À quoi ça sert.** Une catégorie est un type d'activité : « Cours », « Stage »… Chaque discipline appartient à une catégorie, choisie à sa création et qui ne se change plus ensuite.

**Avant de commencer.** Être administrateur. Panneau de contrôle → **Catalogue des activités** → **Catégories d'activités**.

## Les étapes

1. Cliquez sur **Créer une catégorie**.
2. Son **type** : un nom unique.
3. Cliquez sur **Créer**. Son dossier est créé dans la bibliothèque.

Une catégorie à laquelle des disciplines sont rattachées ne peut pas être supprimée.
