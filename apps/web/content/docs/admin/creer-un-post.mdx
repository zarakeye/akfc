**À quoi ça sert.** Un post est un article : une annonce, un compte rendu, une invitation. Publié, il apparaît sur la page d'accueil, dans le mur **Actualités du club**, où les membres peuvent réagir et commenter.

**Avant de commencer.** Être administrateur. Panneau de contrôle → **Éditorial & pages** → **Posts**.

## Les étapes

1. Cliquez sur **Créer un article**.
2. Donnez un **titre** : c'est le seul champ obligatoire.
3. Choisissez la **date de publication** : vide, l'article reste un brouillon que seuls les administrateurs voient ; une date passée le publie ; une date future programme sa publication.
4. Composez le **contenu** avec le constructeur : textes, images, documents.
5. Cliquez sur **Créer** : la page de l'article s'ouvre.

## Ensuite

La liste des posts montre le statut de chacun et sa date de publication. **Supprimer** retire l'article avec ses commentaires, ses réactions et ses sondages.
