**À quoi ça sert.** Les groupes décident de ce que voient les membres : les documents adressés à un groupe, l'espace collaboratif d'un groupe. Le groupe **Administrateurs** donne les droits d'administration.

**Avant de commencer.** Être administrateur. Panneau de contrôle → **Membres & accès** → **Groupes de membres**.

## Les étapes

1. Cliquez sur **Créer un groupe**.
2. Son **nom** : « Bureau », « Compétition »…
3. Son **groupe parent** : les membres d'un groupe parent ont accès, au même niveau, à l'espace de ses sous-groupes. Sans choix, le groupe est rattaché à **Administrateurs**.
4. **Espace collaboratif** : coché, le groupe reçoit un dossier partagé, où chaque membre est éditeur ou lecteur.
5. Cliquez sur **Créer**.

## Ensuite

Ouvrez le groupe depuis la liste pour y **ajouter** des membres et régler leurs accès : voir [Gérer un groupe](/docs/admin/gerer-un-groupe).
