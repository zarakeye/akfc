**À quoi ça sert.** Un évènement est un rendez-vous du club qui n'est ni un cours ni un stage : une démonstration, une fête, une conférence.

**Avant de commencer.** Être administrateur. Panneau de contrôle → **Programme** → **Évènements**.

## Les étapes

1. Cliquez sur **Créer un évènement**.
2. **Identité et publication** : le label, le slug, l'audience et l'organisateur, obligatoires. La date de publication : vide, c'est un brouillon ; future, la publication est programmée.
3. **Rattachement**, au moins un : des disciplines du club, des libellés externes, ou une origine culturelle.
4. **Contenu** : la présentation de l'évènement, composée avec le constructeur, puis sa **présentation synthétique** pour la page Agenda.
5. Cliquez sur **Créer**.

Comme un stage, l'évènement est créé sans date : ses séances s'ajoutent depuis son édition ([Ajouter des séances](/docs/admin/ajouter-des-seances)).
