**À quoi ça sert.** Le tableau de bord (`/dashboard`) réunit tout ce qu'un administrateur peut faire sur le site. On y arrive par votre menu, en haut à droite : **Dashboard**.

**Avant de commencer.** Être administrateur, c'est-à-dire membre du groupe marqué **Admin**.

## Le panneau de contrôle

À gauche, le **Centre de contrôle** range les pages d'administration par section :

- **Demandes** : les demandes reçues (visible aussi des membres qui traitent une catégorie de demandes) ;
- **Membres & accès** : utilisateurs, groupes de membres ;
- **Catalogue des activités** : familles, disciplines, catégories d'activités, origines ;
- **Programme** : cours, stages, évènements ;
- **Éditorial & pages** : pages éditoriales, posts, flash info ;
- **Médiathèque** : bibliothèque, galeries ;
- **Configuration & outils** : réglages du site, registre RGPD, laboratoire de rendu, et les deux documentations.

Le **+** à droite d'un élément ouvre directement le formulaire de création. Un titre de section se replie d'un clic. Sur un téléphone ou une fenêtre étroite, le panneau s'ouvre par le bouton **Panneau de contrôle**.

## La page d'accueil

**Mes informations** (votre fiche, et **Éditer** pour la modifier), puis **Contenus** : des raccourcis vers les disciplines, les familles, les cours, les origines et les posts.
