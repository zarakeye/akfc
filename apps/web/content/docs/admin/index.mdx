Cet espace est réservé aux administrateurs. Il décrit, page par page du tableau de bord, chaque action possible : à quoi elle sert, ses prérequis, ses étapes, son résultat et les erreurs fréquentes.

Chaque fiche se termine, quand il existe, par un tutoriel interactif. Il se déroule sur la vraie page : l'écran s'assombrit, seul l'élément de l'étape en cours reste actif, et l'on passe à l'étape suivante en faisant l'action demandée. Échap l'interrompt à tout moment.

<TourLauncher id="admin.posts.create" />

<Callout type="warning">
Les tutoriels agissent sur les vraies données. Ceux qui créent un élément le créent en brouillon, sous un nom du type « Exemple (tuto) », que vous pouvez supprimer ensuite depuis la liste (colonne **Supprimer**).
</Callout>
