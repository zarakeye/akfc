**À quoi ça sert.** Un flash info est un message court — une fermeture exceptionnelle, un résultat de vote — qui défile dans le **ruban**, sous l'en-tête de toutes les pages publiques. Un clic sur le ruban ouvre le panneau **Flash info**, avec le texte complet et un bouton vers le lien du flash info s'il y en a un. Pour un article complet, avec images et commentaires, écrivez plutôt un [post](/docs/admin/creer-un-post).

**Avant de commencer.** Être administrateur. Panneau de contrôle → **Éditorial & pages** → **Flash info**.

## Les étapes

1. Cliquez sur **Créer un flash info**.
2. Un **titre** et un **corps** (600 caractères au plus) : les deux sont obligatoires.
3. Un **lien**, si besoin : vers un post du mur, une page du site ou une adresse externe.
4. La **date de publication** : vide, c'est un brouillon ; passée, le flash info est publié ; future, sa publication est programmée.
5. La **date d'expiration** : passée cette date, le flash info quitte le ruban de lui-même. Elle doit être postérieure à la publication.
6. Cliquez sur **Créer** : la liste des flashs info s'affiche.

## Ensuite

La liste donne le statut de chaque flash info : **Brouillon**, **Programmée le…**, **Publiée le…** ou **Expirée**. Un clic sur une ligne ouvre sa modification ; la colonne de droite le supprime.
