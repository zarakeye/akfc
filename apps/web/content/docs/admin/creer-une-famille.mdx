**À quoi ça sert.** Une famille regroupe des disciplines sous un même titre dans le menu **Nos disciplines** (« Kung-fu », par exemple).

**Avant de commencer.** Être administrateur. Panneau de contrôle → **Catalogue des activités** → **Familles**.

## Les étapes

1. Cliquez sur **Créer une famille**.
2. Son **nom** ; le **slug** se remplit d'après lui.
3. Son **ordre d'affichage** : les plus petits nombres en premier dans le menu.
4. Cliquez sur **Créer**.

On range ensuite une discipline dans sa famille depuis le formulaire de la discipline (**Origine et classification**).
