**À quoi ça sert.** Transmettre aux membres un document du club : le compte rendu de l'assemblée générale pour tous, un planning pour un groupe, une attestation pour une seule personne. Ils le retrouvent dans **Mes documents**, où un badge signale ce qu'ils n'ont pas encore lu.

**Avant de commencer.** Être administrateur, et que le fichier soit dans la [bibliothèque](/docs/admin/la-bibliotheque). Le fichier n'est pas copié : le document des membres pointe vers lui.

## Mettre un fichier à disposition

1. Dans la bibliothèque, **clic droit** sur le fichier → **Rendre disponible aux membres**.
2. **Titre affiché (optionnel)** : sinon, les membres voient le nom du fichier.
3. **Audience** :
   - **Tous les membres**, y compris ceux qui adhéreront plus tard ;
   - **Des membres précis** : cochez des **Groupes**, des **Membres**, ou les deux.
4. Cliquez sur **Mettre à disposition**.

Un document adressé à un groupe suit le groupe : un membre qui y entre le reçoit, un membre qui en sort ne le voit plus.

Pour les PDF que vous envoyez, le formulaire **Ajouter des fichiers** propose aussi l'option **Rendre les PDF disponibles aux membres** : chaque PDF arrivé est mis à disposition dans la foulée.

## Retirer un document

Le même **clic droit** → **Rendre disponible aux membres** sur un fichier déjà à disposition indique « Ce fichier est déjà à disposition des membres », avec **Retirer des documents**. Le fichier reste dans la bibliothèque ; seuls les membres ne le voient plus.

<Callout type="info">
Un fichier mis à disposition ne peut pas être envoyé à la corbeille : retirez-le d'abord des documents. Les dépôts que les membres font dans l'espace de leur groupe deviennent eux aussi des documents de ce groupe, sans passer par ici.
</Callout>
