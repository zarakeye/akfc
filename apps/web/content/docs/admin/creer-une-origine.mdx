**À quoi ça sert.** Une origine culturelle (« Chine », « Fujian »…) se choisit dans les formulaires des disciplines, des stages, des évènements et des galeries.

**Avant de commencer.** Être administrateur. Panneau de contrôle → **Catalogue des activités** → **Origines**.

## Les étapes

1. Cliquez sur **Créer une origine**.
2. Son **nom**, unique ; le **slug** se remplit d'après lui.
3. Une **description**, facultative.
4. Ses **métadonnées**, facultatives : pays, région, drapeau, période historique. Le drapeau s'affiche à côté de l'origine.
5. Son **ordre d'affichage**.
6. Cliquez sur **Créer**.
