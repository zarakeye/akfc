**À quoi ça sert.** Un cours est un créneau qui revient chaque semaine : « le mardi de 18h30 à 20h, pour les adultes ».

**Avant de commencer.** Être administrateur, et que sa discipline existe. Panneau de contrôle → **Programme** → **Cours**.

## Les étapes

1. Cliquez sur **Créer un cours**.
2. **Le créneau** : la discipline (obligatoire), le public, le jour, l'heure de début et de fin (la fin après le début), l'instructeur, et les prérequis, un par ligne.
3. **Le contenu de la page** du cours, composé avec le constructeur.
4. Cliquez sur **Créer**.

<Callout type="warning">
Un cours n'a pas de brouillon : dès sa création, il est visible sur le site si sa discipline est publiée.
</Callout>
