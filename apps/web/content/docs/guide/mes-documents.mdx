**À quoi ça sert.** Retrouver les documents du club (règlement, calendriers, comptes rendus…) et ceux qui ne concernent que vous.

**Avant de commencer.** Être connecté. La page s'ouvre depuis votre menu : **Mes documents**.

## Trois familles

- **Documents du club** : pour tous les membres.
- **Documents de groupe** : pour les membres d'un groupe ; le nom du groupe est indiqué.
- **Vos documents personnels** : adressés à vous seul.

Une famille vide n'est pas affichée.

## Lire un document

1. Cliquez sur un document : il s'ouvre dans un panneau de lecture.
2. L'ouvrir le marque comme **lu** : le badge **Nouveau** disparaît de la liste. Le bouton **Non lu** le remet en non lu, pour y revenir plus tard.
3. **Télécharger** l'enregistre sur votre appareil, pour le garder ou l'imprimer.
