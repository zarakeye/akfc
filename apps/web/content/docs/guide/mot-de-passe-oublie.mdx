**À quoi ça sert.** Retrouver l'accès à votre compte quand vous ne vous souvenez plus du mot de passe.

**Avant de commencer.** L'adresse e-mail de votre compte, et l'accès à cette boîte.

## Les étapes

1. Sous le formulaire de connexion, cliquez sur **Mot de passe oublié ?**.
2. Tapez l'adresse e-mail de votre compte.
3. Cliquez sur **Envoyer le lien**.
4. Ouvrez l'e-mail reçu et suivez le lien : il ouvre une page où vous choisissez le nouveau mot de passe.

## Ce qu'il faut savoir

- Le lien est valable **30 minutes**, et ne sert qu'une fois.
- Le site affiche le même message que l'adresse ait un compte ou non : c'est voulu, pour ne pas révéler qui est inscrit. Si aucun e-mail n'arrive, vérifiez l'adresse tapée et vos indésirables.
- Une nouvelle demande dans les **2 minutes** qui suivent la précédente n'envoie pas de second e-mail : attendez le premier.
