Cette documentation explique la conception et le développement complet d'une application réelle : le site et l'outil de gestion d'un club d'arts martiaux, en production. Chaque choix y est présenté avec ce qui a amené à lui et ce qu'il permet, puis avec le code qui l'implémente.

Les parties se lisent dans l'ordre, qui est celui dans lequel on construirait le projet : le socle, une vitrine publique, l'écriture des données, la connexion, le contenu et ses fichiers, la mise en ligne, puis les membres. Un sujet peut revenir quand le projet en a de nouveau besoin (« Données (1) » pour lire, « Données (2) » quand il faut écrire ; « Qualité (1) », puis « Qualité »). La documentation est en cours de réorganisation dans cet ordre, phase par phase ; le chapitre « Avant de commencer » explique comment la lire.
