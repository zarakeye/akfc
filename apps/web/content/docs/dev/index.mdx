Cette documentation explique la conception et le développement complet d'une application réelle : le site et l'outil de gestion d'un club d'arts martiaux, en production. Chaque choix y est présenté avec ce qui a amené à lui et ce qu'il permet, puis avec le code qui l'implémente.

Les parties se lisent dans l'ordre. On commence par installer le projet et apprendre sa façon de travailler, puis on descend couche par couche jusqu'au déploiement.
