# Ouvrir le site

Attendez le ✅ dans le terminal, puis ouvrez :

- **[Le site AKFC]({{TRAFFIC_HOST1_3010}})**
- **[La boîte mail de la démo (Mailpit)]({{TRAFFIC_HOST1_8025}})** : tous les e-mails du site y arrivent.

Mot de passe pour tous les comptes : `sandbox-demo`

| Compte | Pour voir |
|---|---|
| `admin@sandbox.local` | l'administration : médiathèque, droits à l'image, pages, demandes |
| `membre@sandbox.local` | la vie d'un membre majeur : son espace, son droit à l'image |
| `mineur@sandbox.local` | un mineur : son parent valide par e-mail (dans Mailpit) |
| `support.sam@sandbox.local` | un bénévole du support, qui n'est pas administrateur |

Le panneau de la démo, en bas à gauche du site, propose des **parcours guidés** par rôle : un curseur
montre où cliquer, c'est vous qui faites chaque geste.

Si une page reste blanche, rechargez-la : le site peut finir de démarrer.
